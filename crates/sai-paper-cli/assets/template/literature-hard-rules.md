# 文献完全性ルール

このテンプレートは、文献情報の捏造を防ぎ、根拠なしの記述を明示するためのエージェント向け規則です。

## ルール 1: 文献を絶対に捏造しない

以下を絶対に発明・推測してはいけない:
- PMID, DOI, arXiv ID
- 論文タイトル、著者名、ジャーナル名
- 掲載年、巻号、ページ
- 被引用数、Impact Factor、h-index
- 臨床試験登録番号（NCT, ChiCTR など）
- 著者の所属機関、メールアドレス

出典は **API の返り値** のみ。

## ルール 2: 不確実な情報に必ずマークをつける

### Case A: API 返り値に記載なし（取得失敗）

論文の Impact Factor が取得できない場合:
```
Impact Factor: [利用不可]
```

著者の h-index が見つからない場合:
```
h-index: [利用不可]
```

### Case B: モデル学習データからの知識（未検証）

訓練データからの一般的な知識であり、ユーザーの文献から確認されていない場合:
```
[未検証: モデル学習データ由来、ユーザーの参考資料で確認されていません]
```

### Case C: API エラー

検索に失敗した場合:
```
[取得失敗 — 手動確認をお願いします]
```

## ルール 3: GAP マーカー

主張を裏付ける文献が必要だが、ユーザーがまだ読んでいない場合:
```
[GAP: 推奨検索: <キーワード>]
```

例:
```
この機構の詳細については、近年の研究では X という仮説が提唱されている。
[GAP: 推奨検索: XYZ mechanism ferroptosis 2023:2024]
```

## ルール 4: 引用のスコープ

ノート、ディスカッション、提案文書での引用は:
- ユーザーが提供した PDF/抄録から得た情報
- または、Semantic Scholar/PubMed で **確認済み** の論文（paperId/PMID がある）

のみとする。

訓練データからの背景知識は:
```
（分野背景 — ユーザーが一次資料で検証してください）
```

と明記する。

## ルール 5: 引用の書き方

引用は、機械で拾える決まった形で書く。`(Smith 2020)` のような著者と年だけの書き方はしない（機械で拾えない）。

- Library にある論文: `[#37]`。場所まで分かるときは `[#37 §3.2]`（章の番号か名前）/ `[#37 p.5]`（ページ）/ `[#37 Fig.3]`（図）。複数は `[#37, #40]`。
- Library に無い論文: `[DOI:10.1000/xyz]` / `[arXiv:2401.12345]` / `[PMID:12345678]`。
- 確かめられないもの: `[未確認: 著者 年 タイトル]`。
- 数値（%・p 値・人数・精度など）を書くときは、同じ文に必ず引用を付ける。
- 検索結果の `cite` の欄の文字列は、そのまま使ってよい。

例:
- 1 文に 1 つの引用: `この手法は既存研究より精度が高い [#37]。`
- 場所付き: `Transformer の注意機構はスケールに比例して性能が伸びる [#37 §3.2]。`
- Library に無い論文: `この仮説は別の研究でも報告されている [arXiv:2401.12345]。`
