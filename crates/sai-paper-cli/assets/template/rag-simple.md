# RAG 単回検索ガイド

Library 内の論文・ノート・ドキュメントを 1 回の hybrid 検索で調べるシンプルな方法。

## ステップ 1: インデックス状態の確認

```bash
sai-paper index status --json
```

チャンク化と埋め込みが完了しているか確認する。

## ステップ 2: 検索クエリの構築

ユーザーからの質問を自然言語として解釈。例:
- 「この研究分野の方法論的な限界は何か」
- 「既読論文の中で免疫応答について論じているものはどれか」

複数のキーワードで試すのも効果的。

## ステップ 3: hybrid 検索の実行

```bash
sai-paper find "<クエリ>" \
  --mode hybrid \
  --top-k 10 \
  --scope all \
  --json
```

オプション説明:
- `--mode hybrid`: word（単語）と vector（意味）の両方で検索して再ランク
- `--top-k 10`: 上位 10 件を返す
- `--scope all`: 論文、ノート、ドキュメント全体から検索
- `--json`: JSON で返す

## ステップ 4: 結果の解釈

各ヒットについて以下を確認:
- **source_kind**: `abstract` / `body` / `note` / `document` のどれか
- **paper_id**: 論文 ID（論文の場合）
- **title / authors / year**: 出典情報
- **text**: ヒットしたテキスト
- **score**: スコア（高いほど関連度が高い）

## ステップ 5: 出典付きでまとめる

各ヒットについて以下の形式で記録:

```markdown
## [質問への回答]

[回答本文 — 根拠を明記]

### 出典

1. **[論文タイトル]** （[著者], [年]）  
   source_kind: [kind]  
   paper_id: [id]  
   DOI: [DOI がある場合]

2. **[ノート / ドキュメント]**  
   パス: [パス]

```

## 既知の注意

- **日本語の単語検索**: `--mode word` は日本語に当たらない（FTS5 のトークナイザの制限）。日本語ノートを検索する場合は埋め込みサーバを起動した上で `--mode hybrid` または `--mode vector` を使う。
- **スコアの相対性**: スコアは絶対値ではなく相対的。上位のヒットの方が関連度が高い。

## 単回検索向けの工夫

- 最初から broad query で試す（一般的な用語）
- 10-20 件の結果を読んで、さらに掘り込むかどうか判断
- 同じ論文の複数セクションが引っかかった場合は、その論文を優先的に読む

## 次のステップ

結果が不十分な場合は、rag-deep-search テンプレートで複数回のクエリ拡張と再ランクを試す。
