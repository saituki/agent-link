# 実装ガイドの書式（doc-guide）

kantoku が実装全体を指揮するための地図である。**各実装計画書の中身は写さず、トークンで参照する。** 同じ内容を 2 か所に書くと、片方が古くなるためである。

- ファイル名: `guide.md`（改訂は `guide-r2.md`）
- description: `実装ガイド: <件名>（<ID の範囲>）`
- 実装計画書を先に保存し、そのトークンを使ってガイドを書く。

```markdown
# 実装ガイド: <件名>

## ゴール
<全体で何を達成するか。完了したときにユーザーが確認できること>

## 実装計画書の一覧
| ID | 件名 | 文書 | 書くファイル | 依存 | 並列 |
|---|---|---|---|---|---|
| U01 | … | waggle:<tok>:path:.sai/outputs/*/<run_id>/unit-U01-….md | a.rs | - | 可 |

## 実行順序
<依存の図またはリスト。直列にする理由、並列にしてよい組>

## 所有権の表
<ファイル × ID。1 つのファイルを書けるのは 1 つの ID だけ。重なるなら直列にする理由>

## 共有契約
<複数の計画書が共有する取り決めの一覧。各計画書にも全文を写してある>

## 全体の完了条件
| 条件 | 担当 ID | 確認方法 |
|---|---|---|

## 統合と検証
<全作業をマージしたあとに kantoku が行う確認（ビルド・テスト・手動確認）>

## 決定事項と理由 / 採用しなかった案
<kantoku が議論をやり直さないための記録>

## リスクと対処
<起きそうな問題と、kantoku が自分で決めてよい範囲・ユーザーに聞くべき範囲>

## 参照文書
<要件の元になった文書など。waggle:<tok>:path:… の形で>
```
