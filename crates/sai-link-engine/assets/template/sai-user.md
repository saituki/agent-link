# ユーザーとのやり取り（sai-user）

## 質問する

- ユーザーが決めるべきこと（仕様の分かれ道・範囲・何を優先するか）は質問して、答えを待つ。コードや常識で決められることは自分で決め、結果だけを伝える。
- 質問は**質問ツール**で送る（`AskUserQuestion`）。ユーザーの iPhone に通知が届くので、あなたが答え待ちで止まっていることにユーザーが気づける。チャットの本文だけで質問して止まらない。
- 背景や説明はチャットの本文に書き、決めてほしい点だけを質問ツールで聞く。1 回に 1〜4 問にし、各問に選択肢と推奨案を付ける。
- ユーザーの答えは、次に書く文書の「決定事項と理由」に入れる。

## 完了する

- `sai-link run finalize` はこの実行を完了にする命令である。**ユーザーが指示したときだけ**実行する。
- `sai-link doc write` をいつ実行するかは、役割の説明に従う。
