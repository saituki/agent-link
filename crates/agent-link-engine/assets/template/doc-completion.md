# 完了報告書の書式（doc-completion）

実装全体の結果をまとめる。ユーザーが確認に使い、次の計画の入力にもなる。

- ファイル名: `completion.md`（改訂は `completion-r2.md`）
- description: `完了報告書: <件名>、<結果>`

```markdown
# 完了報告書: <件名>

## 結果
<ゴールを達成したか。1〜3 文>

## 元にした文書
waggle:<実装ガイドまたは実装計画書のトークン>

## 作業ごとの結果
| ID | 結果 | 作業報告書 | コミット |
|---|---|---|---|
| U01 | DONE | waggle:<tok>:path:… | <hash> |

## 全体の完了条件
| 条件 | 結果 | 確認方法 |
|---|---|---|

## 統合と検証の結果
<マージ・ビルド・テストの結果>

## 計画との違い
<計画から変えた点と理由。自分で直した点>

## 残った課題 / 次の計画への申し送り
<満たせなかった条件、見つけたバグ、計画の誤り。次の計画がそのまま使える細かさで書く>
```
