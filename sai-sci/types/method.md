# METHOD_DRIVEN

手元で新しい手法が使える状態が先にあり、「それを何に使うか」を決める型である。型は、雛形の問いのうち、どれが最初から seed で回答されているかで決まる。最初から回答されているのは、手法（method）である。解く問題・対象・評価指標は未回答で始まる。手法の中身は既に決まっているので、使う場面と比べる相手を探すことが仕事になる。

手法が劣っていても、評価の軸が違えば使う理由ができる。その軸を、評価指標の下の root から探す。

典型例は、自己教師ありの時系列分解を手元にもっている状態で、「てんかん焦点の短い区間の時系列を表示できるか」を考えるものである。手法は決まっているが、解く問題・対象・評価指標は決まっていない。

## 軸
- task
- target
- data
- method
- output
- metric

## ROOT_SHAPE
- 先に深く育てる軸: 手法（method）を 2 段まで育てる（入力・出力・条件で分ける）。
- 大分類だけ置く軸: task・target・data・output・metric。評価の軸は、metric の下の root から探す。
- 未回答で始まる問いは、理由なく回答（固定）にしない。回答にするときは、その理由を seed に書く。

## seed（D）
- 最初から回答されていることが多い: 手法（method）
- 未回答で始まりやすい: 解く問題（task）・対象（target）・評価指標（metric）
