# DATA_DRIVEN

手元にあるデータセットが先にあり、「このデータで何が言えるか」を問う型である。集めたときの目的とは限らない。型は、雛形の問いのうち、どれが最初から seed で回答されているかで決まる。最初から回答されているのは、データ（data）である。解く問題・手法・出力は未回答で始まり、序盤はデータの意味を読む時間に使われる。

典型例は、病院の生理信号が 1 つのデータベースにまとまっていて、その中のどの話をするかから始めるものである。データの型は決まっているが、解く問題も比較の相手も決まっていない。

## 軸
- task
- target
- data
- method
- output
- metric

## ROOT_SHAPE
- 先に深く育てる軸: データ（data）を 2 段まで育てる（型・印で分ける）。
- 大分類だけ置く軸: task・target・method・output・metric。seed の回答が出てから深くする。
- 未回答で始まる問いは、理由なく回答（固定）にしない。回答にするときは、その理由を seed に書く。

## seed（D）
- 最初から回答されていることが多い: データ（data）
- 未回答で始まりやすい: 解く問題（task）・手法（method）・出力（output）
