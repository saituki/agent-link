# PROBLEM_DRIVEN

現場で、今のやり方では形にならない問題が残っており、「これをどうにかしたい」という課題から研究が始まる型である。型は、雛形の問いのうち、どれが最初から seed で回答されているかで決まる。最初から回答されているのは、解く問題（task）と背景である。手法・出力・評価指標は未回答で始まり、課題を観測できる問いに落としたあとで決める。

課題が 1 つに決まらないまま手法を並べ始めると、比較の基準が立たず、どこにも進めない。序盤は現場の課題を研究の問題として言い切ることに労力を使う。

典型例は、てんかん外科の支援という大目的から「頭皮脳波だけで発作部位を推定できるか」という問題に絞るものである。解く問題が決まっているので、残りは手法・出力・評価指標を、軸の下の root から選ぶことに使う。

## 軸
- task
- target
- data
- method
- output
- metric

## ROOT_SHAPE
- 先に深く育てる軸: 解く問題（task）を 2 段まで育てる。
- 大分類だけ置く軸: target・data。手法（method）・出力（output）・評価指標（metric）は、seed の回答が出てから深くする。
- 未回答で始まる問いは、理由なく回答（固定）にしない。回答にするときは、その理由を seed に書く。

## seed（D）
- 最初から回答されていることが多い: 解く問題（task）・背景
- 未回答で始まりやすい: 手法（method）・出力（output）・評価指標（metric）
