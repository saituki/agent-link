# PROBLEM_DRIVEN

現場で、今のやり方では形にならない問題が残っており、「これをどうにかしたい」という課題から研究が始まる型である。型は、seed のどの項目が最初から決定かで決まる。最初から決まっているのは、解く問題（task）と背景である。手法・出力・評価指標は空欄で始まり、課題を観測できる問いに落としたあとで決める。

課題が 1 つに決まらないまま手法を並べ始めると、比較の基準が立たず、どこにも進めない。序盤は現場の課題を研究の問題として言い切ることに労力を使う。

典型例は、てんかん外科の支援という大目的から「頭皮脳波だけで発作部位を推定できるか」という問題に絞るものである。解く問題が決まっているので、残りは手法・出力・評価指標を、軸の下の root から選ぶことに使う。

## Q
- task
- target
- data
- method
- output
- metric

## ROOT_SHAPE
- 先に深く育てる軸: 解く問題（task）を 2 段まで育てる。
- 大分類だけ置く軸: target・data。手法（method）・出力（output）・評価指標（metric）は、seed の決定が出てから深くする。
- 空欄で始まる軸は、理由なく「決定」にしない。決定にするときは、その理由を seed に書く。

## SEED
- 決定になりやすい: 解く問題（task）・背景
- 空欄で始まりやすい: 手法（method）・出力（output）・評価指標（metric）
