# PHENOMENON_DRIVEN

必ず起きている現象を先に捉え、「なぜそうなるのか」を問う型である。型は、seed のどの項目が最初から決定かで決まる。最初から決まっているのは、対象（target。現象を含む）と背景である。データ・手法・評価指標は空欄で始まり、説明の型と確かめ方が決まってから、はじめて研究になる。

使う手法より先に、観察できる事実がある。現象を説明として書かず、誰が何の計測で見たかを添えて書く。

典型例は、安静時と運動後で指標の挙動が変わるという現象から、その切り替わりがどの仕組みで起きるのかを調べるものである。対象と現象は用意済みだが、原因を測るデータと確かめ方はまだ決まっていない。

## Q
- task
- target
- data
- method
- output
- metric

## SEED
- 決定になりやすい: 対象（target。現象を含む）・背景
- 空欄で始まりやすい: データ（data）・手法（method）・評価指標（metric）
