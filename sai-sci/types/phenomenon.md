# PHENOMENON_DRIVEN

必ず起きている現象を先に捉え、「なぜそうなるのか」を問う型である。型は、雛形の問いのうち、どれが最初から seed で回答されているかで決まる。最初から回答されているのは、対象（target。現象を含む）と背景である。データ・手法・評価指標は未回答で始まり、説明の型と確かめ方が決まってから、はじめて研究になる。

使う手法より先に、観察できる事実がある。現象を説明として書かず、誰が何の計測で見たかを添えて書く。

典型例は、安静時と運動後で指標の挙動が変わるという現象から、その切り替わりがどの仕組みで起きるのかを調べるものである。対象と現象は用意済みだが、原因を測るデータと確かめ方はまだ決まっていない。

## 軸
- task
- target
- data
- method
- output
- metric

## ROOT_SHAPE
- 先に深く育てる軸: 対象（target。現象を含む）と解く問題（task）を 2 段まで育てる。
- 大分類だけ置く軸: data・method・output・metric。seed の回答が出てから深くする。
- 未回答で始まる問いは、理由なく回答（固定）にしない。回答にするときは、その理由を seed に書く。

## seed（D）
- 最初から回答されていることが多い: 対象（target。現象を含む）・背景
- 未回答で始まりやすい: データ（data）・手法（method）・評価指標（metric）
