# ⚖ 比べる

## 依頼
{{input.task_text}}

## 役割
「今回の範囲」の節点が「選ぶ」または「並べる」項目のときに使う。候補を同じ条件で並べ、根拠の ID を添えた表にして、選ぶ項目のときは推奨を 1 つ出す。

比較の軸は範囲の「土壌」の「価値の軸」から取る。軸は自分の都合で増やさない。軸の数がそのまま比較の細かさを決める。

このブロックは**点数を付けない**。候補全体を「8 点」とは書かない。対象・データの型・出力の型・制約ごとに「一致・部分・不一致」と根拠を書く表で示す。各セルの根拠は知見の ID（`F<数>`）で辿れるようにする。

推奨を出すときにも反証を探す。選んだ候補に不利な知見があれば伏せずに書き、外す候補とその理由を `rejected` に残す。探したが見つからなければ、「探したが見つからなかった」と report に書く。

共通は次のとおり。出典は `literature-hard-rules` に従い、木・mind.md・state.md・tree.md を直接書き換えず、成果はすべて提案で出す（木に触れる操作は利用者が行う）。

### 手順
1. **節点の種類を確かめる。** 範囲の節点の項目が「選ぶ」か「並べる」かを見ます。どちらの型にも当てはまらなければ手を付けずに利用者に確認します。節点の型が `choose` か `list` のどちらにも当たらないことも確かめます。
2. **候補を集める。** 既に項目に付いている候補を全て確認します。無いときは `add_option` で候補の提案を出します。候補の追加も提案なので、そのままでは入りません。
3. **軸を範囲から取る。** 範囲の「土壌」の「価値の軸」を読み、比較に使う軸を並べます。軸が範囲に書かれていなければ節点の種類と項目から導出し、導出した軸とその理由を report に書きます。
4. **候補ごとの根拠を集める。** 候補ごとに次を実行し、論文ごとの根拠を集めます。
   ```sh
   sai-moon-paper find "<候補の語>" --node <候補の N> --each 3 --json
   ```
   `--each` は少数の論文に偏らないようにするための指定です。根拠が薄い候補は「根拠が薄い」と書き、推測で埋めません。検索の範囲を広げたときは `--widen <理由>` を付けます。
5. **反証を探す。** 各候補について、損なう結果を示す知見を必ず探します。分かった知見は `add_finding` で、支持・反証の向きを付けて提案します。探したが見つからなかったときは、そのことを書きます。見つかったときは向き `refute` の知見として書き、比較表にも入れ、有利な候補と同じ重さで並べています。
6. **比較表を作る。** 軸ごとに、候補がどう違うかを根拠の ID つきで並べます。根拠が無い欄は「根拠なし」と書き、空にはしません。
7. **節点の種類に応じてまとめる。** 比較に使った論文は `link` で節点に結び付けます。
   - **選ぶ**項目のときは、推奨を 1 つ選び `decide` の提案にします。`evidence` に支持する知見の ID を入れ、`rejected` に外す候補と理由の組を入れ、`counter_searched` は反証を探したら `true` にします。決め切れないときは外さず、根拠が足りない地点を report に書いて止めます。採用と却下は利用者が行います。
   - **並べる**項目のときは、分類と比較表を作り、抜けているカテゴリを `add_option` で候補として提案します。 眠ったままにしたい候補には `option_state` を提案します。こちらでは何も決めません。
8. **利用者に仕分けてもらう。** 提案を出したら一覧を見せ、報告します。

## 評価の観点
- 軸が範囲の「価値の軸」に対応しているか。軸を自分の都合で増やしていないか。
- 表の各セルに根拠の ID が付いているか。根拠の無い欄を推測で埋めていないか。
- 論文と項目の一致を点数で表していないか（一致表だけか）。
- 根拠が少数の論文に偏っていないか。`--each` を付けているか。
- 反証を探したか。探したが見つからなかったことを書いているか。
- 推奨を出すとき、`evidence` と `rejected` の両方に具体的な ID が入っているか。
- 外す候補に理由が付いているか。理由の無い却下をしていないか。
- 並べる項目では、抜けているカテゴリを指摘しているか。

## 出力の形
report は次の見出しで、この順のまま書きます。

```markdown
## 比べる候補と軸
## 比較表（候補 × 軸。各セルに根拠の ID）
## 一致表
## 推奨と理由
## 提案したこと
## 範囲外のメモ
```

- **比べる候補と軸** — 節点の種類（選ぶ / 並べる）、候補の一覧、範囲から取った軸の一覧を書きます。軸を導出した場合はその理由も書きます。
- **比較表** — 候補を行、軸を列にする表を書き、各セルに根拠の ID（`F<数>`）を添えます。根拠が無い欄は「根拠なし」と書きます。
- **一致表** — 対象・データの型・出力の型・制約の列を持ち、各行に「一致・部分・不一致」と根拠を書く表にします。点数は付けません。
- **推奨と理由** — 選ぶ項目のときは、推奨を 1 つ、その理由、支持する知見の ID、外す候補と理由、反証を探したかを書きます。並べる項目のときは「推奨は出さない」とその理由を書きます。
- **提案したこと** — 提案 ID（`P<数>`）と op 名、短い理由の表を書きます。
- **範囲外のメモ** — 範囲の外だと分かったこと、保留した理由、根拠が足りなかった点を書きます。
