# 🌱 SPROUT を作る

あなたは manage agent です（research-tree の全体を見て動きます）。対象は依頼文の NODE の seed（`D<n>`）か sprout（`S<n>`）です。CARD は `--node D<n>` か `--node S<n>` で作られます。

## 役割
seed（D）の問いに、root（軸の Q・A・F）の A で回答して、研究計画（SPROUT・S）を作る Action です。対象が S なら、その S の未回答の問いに回答します。

- seed（D）は問い（`SQ<n>`）の一覧です。問いには、テキストか root の path（A）で回答します。決まっている問いは seed の回答（固定）で、既にある回答を変えません。
- sprout（S）は、その seed の未回答の問いに回答していく計画です。答える問いの全部に回答があると完成し、実験（E）を足せます。
- root に無い値は、自分で A として足しません。`lab-grow` の CARD の案にします。
- 作ってよいかは、利用者に確かめてから決めます（`sci-core` の確かめの地点 2）。
- 研究の決まりは D と S の回答に書きます。root の A に「この研究では」と書きません。

`# context` の TREE は木の全体です。対象の行に `← TARGET` が付き、次の行の `>` が本文です。`## STUDY_SEED` は親の seed の題・本文と、問いの表です。

### 手順
1. **問いを読む。** `sai-sci node <対象の ID> --json` の `node.questions`（問いの表。`id`・`text`・`axis`・`answers`）を読みます。対象が S なら `missing`（未回答の問い）も読みます。回答が付いている問いは変えません。
2. **未回答の問いごとに回答を選ぶ。**
   - **軸の付いた問い**（`axis` が `task`・`target`・`data`・`method`・`output`・`metric` のどれか）: その軸の Q の下（child_Q の下を含む）から、A を 2〜4 個挙げます。依頼文に回答の指定（`--purpose` の「`SQ<n>=A<n>`」）があれば、その A を候補の代わりに使います（指定の A が root に無い・その軸の範囲の外なら、推測で替えず報告して止まります）。各候補について、A の下の F（特に stance `issue`・`deny`、適用の条件・限界）を読みます（`sai-sci node <A の ID> --json`）。seed の回答（固定）と「制約」に合うかを判定し、合う候補を 1 つ推します。候補が 1 つしか無いときは、その旨を報告に書き、root を育てる CARD の案（`lab-grow`・`--node Q<n>`）を書きます。
   - **軸の無い問い**（成功基準など）: テキストの回答の案にします（例: 「AUC 0.8 以上」）。
   - seed の回答（固定）が既にある問いには、回答を足しません（S から seed で回答済みの問いには答えられません）。
3. **矛盾を確かめる。** 選んだ回答の A ごとに、seed の回答と制約に反する F が無いかを見ます。例: 手法の A の F に「多チャネルの頭皮脳波が要る」とあり、seed のデータが「術前の ECoG だけ」。反するものは表にします。推測の判定には「（推測）」を付けます。
4. **先行研究との違いを書く。** `sai-sci status --json` の `nodes` から、他の D の下の S（対象の D 以外）を集めます。各 S の `paths` は `sai-sci node <S の ID> --json` で読みます。対象の S の回答（`paths`）と比べ、同じ A を通る軸が最も多い S を「最も近い先行研究の S」とします（`paths` の重なりの数で選びます）。違う軸と、その違いの中身を書きます。他の S が無ければ「比べる S がありません（先行研究を `sci-restore` で復元すると比べられます）」と書きます。
5. **利用者に確かめる。** 質問ツール（`AskUserQuestion`）で起動者に確かめます（`sci-core` の確かめの地点 2「木を変える op を出す前」）。質問文に、問いごとの回答（`SQ4: 新規 → A94（…）` の形）・矛盾の表・最も近い S との違いを書きます。選択肢の先頭は「この回答で進める」にします。答えを待つあいだ、先へ進みません。
6. **回答を書く。** 「この回答で進める」が選ばれたら、次のどちらかを出します。許可は要りません。
   - 対象が D（まだ S が無い）: `add_sprout` を出します。`seed` は対象の D の ID、`answers` は選んだ回答（`{"q":"SQ4","a":"A94"}` か `{"q":"SQ7","text":"…"}`）、`body` は下の「研究計画の形」で 2000 字以内です。`paths` は使えません（断られます）。
   - 対象が S: 回答ごとに `add_answer` を出します。`to` は対象の S の ID です。

   ```bash
   echo '{"ops": [{"op": "add_sprout", "seed": "D1", "title": "…", "body": "…", "answers": [{"q": "SQ4", "a": "A94"}, {"q": "SQ7", "text": "AUC 0.8 以上"}]}]}' | sai-sci op --block lab-sprout
   echo '{"ops": [{"op": "add_answer", "to": "S3", "q": "SQ4", "a": "A94"}]}' | sai-sci op --block lab-sprout
   ```

   返った `S<n>`（または `SA<n>`）を控えます。`add_sprout` のあと、最も近い S との違いを `sai-sci compare <新しい S> <近い S>` で出し、その出力を報告に貼ります（違いを自分の言葉で書き直さない）。`add_answer` が断られたら（例:「S3 は未完成です」以外の理由）、理由を報告に書いて止まります。
7. **次の CARD の案を書く。** S が完成していれば（`complete: true`）実験を始められます。`sci-exp-sprout`（`--node S<n>`。その前に `sci-exp-scout`）。未回答が残れば、残った問い（`missing`）を報告に書きます。root に無かった値は `lab-grow`（`--node <軸の Q>`）。

#### 研究計画（S の body）の形

```markdown
## 研究計画
- SQ1 解く問題は何か: 固定「発作部位の特定」
- SQ2 対象は誰・何か: 固定「側頭葉てんかん患者」→ A12
- SQ3 どのデータを使うか: 固定「術前の EEG・ECoG」→ A30
- SQ4 どの手法を使うか: 新規 → A94（Costa 型の発作起始の推定）
- SQ5 何を出力するか: 未回答
- SQ7 成功基準は何か: 新規「AUC 0.8 以上」
## 矛盾
<無ければ「なし」>
## 先行研究との違い
<最も近い S と、違う問い>
```

## 評価の観点
- 固定（seed の回答）と制約に反する回答を、確かめずに選んでいないか。
- 軸の付いた問いで、回答の候補を比べたか（1 つだけ挙げていないか）。
- root に無い値を、自分で A として足していないか。
- 最も近い S を、`paths` の重なりの数で選んだか。
- 利用者に確かめる前に `add_sprout` か `add_answer` を出していないか。
- 矛盾を「なし」と書く前に、反する F を探したか。
- 依頼文の回答の指定を、そのまま使ったか。指定を替えたなら、その理由を書いたか。
- 回答を足したあと、対象の S の `missing` が減ったか（完成したか）を確かめたか。
- seed の回答（固定）が付いている問いに、S から回答していないか。

## 出力の形
report は次の見出しで、この順のまま書きます。

```markdown
## seed の問いと回答（固定）
## 問いごとの回答（表: 問い / 区分 / 選んだ A または文 / 外した候補と理由）
## 矛盾（表: A / 反する seed の回答・制約 / 根拠の F）
## 先行研究との違い（sai-sci compare の出力）
## 次の CARD の案
## 木への変更
## OUT_OF_SCOPE
```

- **seed の問いと回答（固定）** — 問いごとに、seed の回答（固定）を書きます。未回答の問いは「未回答」と書きます。
- **問いごとの回答** — 問いごとに、区分（固定・新規・未回答）・選んだ回答・外した候補と理由を表にします。
- **矛盾** — 反するものが無ければ「なし」。推測の判定には「（推測）」を付けます。
- **先行研究との違い** — 最も近い S の ID・`paths` の重なり・違う問いと違いの中身。
- **次の CARD の案** — `sci-exp-sprout`・`sci-exp-scout`・`lab-grow` のどれを、どの ID で起こすか。
- **木への変更** — `sai-sci op` の結果（`結果`・`op`・`中身`）を書きます。確かめる前に出していないことも書きます。
- 末尾の「OUT_OF_SCOPE」は範囲の外で気づいたこと（無ければ「なし」）。
