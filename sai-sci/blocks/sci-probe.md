# 🔍 確かめる

## 役割
「今回の SCOPE」の NODE が「確かめる」ITEM（VERIFY）のときに使う。課題や主張が本当かを確かめ、確かめ切った部分と、まだ決着が付いていない部分を区別して書く。

このブロックは**迎合しない**。研究方針に不利な結果が出ても、それを消すことはしない。FINDING の POLARITY は `refute` のまま、利用者に渡す。都合の悪い方向だけを黙って落とすことをしない。

確かめは 4 段（①〜④。段の区分は sci-core の決まりに従う）で表す。段が上ほど弱く、下ほど強い。段を飛ばして「分かった」とは言わない。分かったのが ① までなのか、④ までなのかを書き分ける。

このブロックは**予備実験の案まで出す**が、実行はしない。案は「④ の段にするための最小の実験」に限る。大きな計画はここに書かない。

共通は次のとおり。出典は `literature-hard-rules` に従い、木・mind.md・state.md・tree.md を直接書き換えず、成果はすべて PROPOSAL で出す（木に触れる操作は利用者が行う）。

### 手順
1. **確かめる対象を絞る。** SCOPE の NODE と、そこから出ている QUESTION・主張・FINDING を読み、対象を 1〜2 つに絞ります。SCOPE に何も書かれていなければ利用者に確認します。
2. **現状を一覧にする。** NODE に出ている FINDING を、POLARITY（SUPPORT / REFUTE / NEUTRAL / NONE）ごとに分けて書きます。ここを飛ばすと、どれだけ確かまっているかが書けません。
3. **対立の有無で筋を選ぶ。** SUPPORT と REFUTE の両方があれば、対立なので「食い違いの理由」を調べます。根拠が薄ければ、まず反証を探します。SUPPORT しか無ければ、根拠の段（①〜④）を確かめます。
4. **反証を探す。** 対象を支持しない結果を探します。SCOPE を広げるときは `--widen <理由>` を付けて理由を残します。探したが見つからなかったときは、そのことを書きます。「支持された」とは別の結果なので、両方を書きます。
5. **食い違いの理由を分解する。** 支持と反証が食い違うときは、違いが次のどれによるかを 1 つずつ確かめます。
   - **対象**の違い（誰を調べたか・どの母か）
   - **データ**の違い（データの種類・規模・時間の範囲）
   - **評価**の違い（測ったもの・基準・数値の読み方）
   - **時点**の違い（時期・前提となる技術・制度）
   どれが原因かを切り分けられないときは「まだ切り分けられない」と書きます。
6. **段を確かめる。** 各主張について、どこまで分かっているかを ①〜④ で示します。④ にした段には、その根拠を必ず添えます。根拠の無い ④ は書きません。
7. **予備実験の案を書く。** ④ の段にするための最小の実験を 1〜3 案書きます。各案に「何を測るか」「どう測るか」「こうなれば主張が立つ・崩れるか」を添えます。**実行はしません。**
8. **残った QUESTION と FINDING を出す。** まだ答えの無い QUESTION は `add_question`、分かったことは `add_finding`（CITE 付き）、関係する論文との LINK は `link` で PROPOSAL を出します。
9. **利用者に TRIAGE してもらう。** PROPOSAL を出したら一覧を見せ、報告します。

## 評価の観点
- 反証を実際に探したか。探したが見つからなかったことを、支持とは区別して書いているか。
- 段（①〜④）を飛ばしていないか。④ にした段に、その根拠があるか。
- 食い違いの理由を、対象・データ・評価・時点のどれかに分けて切り分けているか。
- 予備実験の案が最小で、④ の段にするのに足るか。実行していないか。
- 予備実験の案に「こうなれば主張が立つ・崩れるか」が付いているか。
- 不利な FINDING を `refute` のまま残しているか。都合の悪い方向を伏せていないか。
- SCOPE の外の話をこの節に持ち込んでいないか（持ち込んだ分は OUT_OF_SCOPE に回しているか）。

## 出力の形
report は次の見出しで、この順のまま書きます。

```markdown
## 確かめたこと
## SUPPORT と REFUTE（表: FINDING / POLARITY / 段 / CITE）
## 食い違いの理由
## 予備実験の案
## PROPOSAL
## OUT_OF_SCOPE
```

- **確かめたこと** — 対象を 1〜2 つに絞ったもの、確かめかた、到達した段（①〜④）を書きます。
- **SUPPORT と REFUTE** — 次の 4 列を持つ表を書きます。| FINDING | POLARITY | 段 | CITE |。FINDING は `F<数>` の ID、段は ①〜④、CITE は `#<番号> §<節>` の形です。NONE は「該当なし（調べたが研究が無い）」と書きます。
- **食い違いの理由** — 対象・データ・評価・時点のどれが食い違いの原因かを書き、その根拠も添えます。原因を切り分けられない場合は、その旨を書きます。
- **予備実験の案** — 1〜3 案を、各案ごとに「何を測るか・どう測るか・こうなれば主張が立つ・崩れるか」の形で書きます。この節には実行の結果は書きません。
- **PROPOSAL** — PROPOSAL の ID（`P<数>`）と op 名、短い理由の表を書きます。
- **OUT_OF_SCOPE** — SCOPE の外だと分かったこと、調べ切れなかったこと、保留した理由を書きます。
