# 論文と Q の一致（sci-match）

論文を Q と照らすブロックが読みます。`sci-core` と合わせて守ります。

論文が Q の条件にどれくらい合うかを、点数にしないで表で示します。条件は、Q とその ★ の O、そして `# context` の `## GUIDE` の `## Extract` の項目から取ります。条件ごとに「一致・部分・不一致」と、その根拠（塊の ID `#37.5.2`）を書きます。

```markdown
| 条件 | research-tree の値（Q・★ の O） | 論文（#37） | 一致 | 根拠 |
|---|---|---|---|---|
| 対象 | 成人のてんかん患者 | 小児 | 不一致 | #37.3.1 |
| データの型 | 頭皮脳波 | 頭皮脳波 | 一致 | #37.3.2 |
| 出力の型 | 発作部位 | 発作の有無 | 部分 | #37.4 |
| 制約 | 少数・多施設 | 単施設 | 部分 | #37.3.3 |
```

- 合計点や重みは書きません。「何が違うか」が分かるように書きます。
- Q の種類によって、照合する条件を変えて構いません（候補を選ぶ Q なら O どうしの比較、確かめる Q なら「どこまで確かめればよいか」）。
