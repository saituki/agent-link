# 分野の観点: 医学・生物医学（medical）

## 問いを整理するときの枠
- まず問いの種類を 1 つ（多くても 2 つ）決める。治療・介入、曝露・リスク、診断精度、予後、機構、実施を混ぜない。
- 治療・介入の比較 → PICO（Population / Intervention / Comparator / Outcome）。
- 曝露・危険因子・疫学 → PECO（Population / Exposure / Comparator / Outcome）。
- 期間・場面・研究デザインが中心なら → PICOTS（PICO に Time / Setting を足す）。
- 診断精度・スクリーニング → 対象の状態 / 対象集団 / 指標検査 / 参照基準 / 精度の指標。
- 予後 → 対象集団 / 予後因子 / アウトカム / 時間軸 / 治療の状況。
- 軸ごとの大分類の例（木の最初の段の A。分け方の基準は細分の Q の本文に書く）: target は「疾患・病態／発達段階／動物モデル／回路・細胞の系」、output は「患者単位の判定／信号・事象の記述／時空間の表現／機序の説明」、method は「計算モデル／動物・細胞の実験／臨床脳波の解析／統計・機械学習」。
- 対象集団は疾患の段階・サブタイプ・重症度まで狭める。狭めるときは範囲外にしたものを明記する。
- アウトカムは臨床的に意味のあるもの（死亡・疾患の発症・機能）を中心にする。
- 検索できる形（疾患名＋介入/曝露＋アウトカム）に落とし、英語の検索語の候補まで作る。

## 証拠の強さの見方
- 研究デザインの階層を出発点にする: 系統的レビュー・メタアナリシス > ランダム化比較試験 > コホート研究 > 症例対照研究 > 症例報告・症例集積 > 基礎研究（細胞・動物）。
- ラベル（RCT、メタアナリシス）だけで強さを決めない。実行の質を必ず併せて見る。
- 実行の質: 割り付けの隠蔽、盲検化、追跡の完全さ、交絡の制御、欠測の扱い、多重性の扱い、解析の事前指定。
- 検証の深さ: 単一の研究か、独立した追試・外部検証・別のデータセットでの再現があるか。
- 統計的有意性や効果量の大きさを、方法の強さの証拠として使わない。
- 臨床試験は登録（ClinicalTrials.gov / jRCT / UMIN など）と事前に決めた主要評価項目を確認する。
- 結論が研究デザインの許す範囲を超えていないか（関連を因果として書いていないか）を確かめる。
- プレプリントか査読済みかを区別し、両者を同じ重さで扱わない。

## よくある落とし穴
- 代理エンドポイント（血圧・検査値などのサーバー指標）を、患者にとって大事な結果（死亡・発症）と同じように扱う。
- 選択バイアス: 対象集団が実際の患者と違う、登録の偏りがある、追跡から脱落した人に偏りがある。
- 多重比較・後付けのサブグループ解析（p 値の切り取り、都合のよいサブグループの強調）。
- 統計的有意性や効果量の大きさを、方法の強さと取り違える。
- 症例報告や単一施設の結果を、そのまま一般化する。
- 関連を因果として述べる、遡及的（後ろ向き）の性能を臨床的有用性として述べる。
- 利益相反や資金源の見落とし。
- 病因・機構の研究（細胞・動物）の結果を、そのまま臨床に当てはめる。
