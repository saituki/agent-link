# 研究方針の木（sai-sci）を手で確かめるチュートリアル

**読み手**: プログラムに慣れていない利用者。
**かかる時間**: 1〜2 時間（エージェントを動かす章を入れると、さらに 30 分ほど）。
**このあとできるようになること**: 研究方針の木の機能をひと通り自分で動かし、画面のどこに何が出るかが分かる。

このチュートリアルでは練習用のプロジェクトを 1 つ作り、次の流れを最初から最後まで体験します。

```
① 準備 → ② 練習用プロジェクトを作る → ③ 画面の見取り図
→ ④ 論文を集める → ⑤ 論文を項目に結ぶ → ⑥ 読む札で読んで知見を書く
→ ⑦ 候補と知見を足す → ⑧ 決める → ⑨ 決めたことを戻す
→ ⑩ 問い・子の項目・文・線 → ⑪ エージェントに頼む → ⑫ 仕分ける
→ ⑬ Dashboard と負債 → ⑭ 根の図と表 → ⑮ 墓標 → ⑯ TUI
→ ⑰ 同じことをコマンドで → ⑱ 片付け
```

練習用のプロジェクトは本物の研究とは別の場所に作ります。何を押しても本物の研究には影響しません。安心して試してください。

## 0. 先に覚えておく言葉

画面によく出る言葉です。今は全部を覚えなくて構いません。分からなくなったらここに戻ってください。

| 言葉 | 意味 | 例 |
|---|---|---|
| 研究方針の木 | 「何を研究するか」を決めるための木。項目・候補・知見がつながっている | ― |
| 項目 | 研究で決めなければならない穴 | 「小目的」「対象」「データの型」 |
| 候補 | 項目に入りうる答えの案 | 小目的の候補「発作の予知」 |
| 知見 | 論文などから分かった 1〜3 文の事実と、その出典 | 「数分先の発作予測で AUC 0.9 前後の報告がある（#1 abstract）」 |
| 出典 | 知見がどこに書いてあったか。`#論文の番号 場所` の形で書く | `#1 abstract`、`#37 §3.2` |
| 向き | 知見が候補を支えるか、否定するか | 支持・反証・中立・該当なし |
| 種の文 | 研究を 1 文で言うためのひな形。決まった項目の値が入る | 「［？対象］の［？データの型］で発作の予知を行う。…」 |
| 関門 | 研究が進んだかを測る関所。上から順に通っていく | 「関門 3/7 データの入手」 |
| 負債 | 後回しにしている片付け物の数 | 「仕分けていない提案 2」 |
| 読む札 | 自分が論文を 1 本読むための作業票 | ― |
| カード | エージェント（pi や cc）に仕事を頼む作業票 | ― |
| 提案 | エージェントが出した「木をこう変えたい」という申し出 | ― |
| 仕分け | 提案を採用するか却下するかを決めること | ― |
| 墓標 | 「この論文は外した」という記録。同じ論文が検索に出なくなる | ― |
| ターミナル | 文字で命令を打つアプリ（Mac の「ターミナル.app」） | ― |

### 命令（コマンド）の打ち方

このチュートリアルでは、次のような灰色の箱に命令が書いてあります。

```bash
echo こんにちは
```

1. ターミナルを開きます（Finder →「アプリケーション」→「ユーティリティ」→「ターミナル」）。
2. 箱の中の文字をコピーして、ターミナルに貼り付けます。
3. `return` キーを押します。

`#` から後ろは説明です。打たなくても構いません（貼り付けても害はありません）。

## 1. 準備

### 1.1 命令が使えるか確かめる

ターミナルで次を打ちます。

```bash
which sai-moon-paper sai-moon-link sai-moon-paper-tui
```

3 行とも `/Users/<あなたの名前>/.local/bin/…` のように出れば準備はできています。
`not found` と出たら、開発者に「`~/.local/bin` に sai-moon の実行ファイルへのリンクを置いてほしい」と頼んでください。

### 1.2 Web の画面（apps/phone）を起動する

ターミナルの窓を**新しく 1 つ**開きます（`⌘ + N`）。この窓は Web の画面を動かし続けるための窓なので、作業中は閉じないでください。

```bash
cd ~/workdir/Sai/sai-moon
PATH=$HOME/workdir/Sai/sai-moon/target/release:$PATH \
  apps/phone/.venv/bin/uvicorn sai_phone.main:app \
  --host 127.0.0.1 --port 8200 --app-dir apps/phone/src
```

`Uvicorn running on http://127.0.0.1:8200` と出たら起動できています。
ブラウザ（Safari や Chrome）で **http://localhost:8200/** を開いてください。

> 止めるときは、この窓で `control + C` を押します。

画面の左（iPhone では下）に、次の 5 つのタブがあります。

```
ホーム / プロジェクト / 会話 / 論文 / 使用量
```

このチュートリアルで主に使うのは **論文** タブです。エージェントを動かす章（⑪）では **プロジェクト** と **会話** も使います。

## 2. 練習用のプロジェクトを作る

### 2.1 フォルダを作って初期化する

もう 1 つターミナルの窓を開き（こちらは命令を打つ窓です）、次を打ちます。

```bash
mkdir -p ~/research/sci-practice
cd ~/research/sci-practice
sai-moon-paper init --sci --type problem
```

- `mkdir -p` はフォルダを作る命令です。
- `cd` はそのフォルダへ移る命令です。
- `sai-moon-paper init --sci --type problem` は、ここを「研究方針の木を使う研究プロジェクト」にする命令です。`--type problem` は研究の型を「課題駆動」にするという意味です。

研究の型は 5 つあります。練習では `problem` を使います。

| `--type` の値 | 名前 | どんな研究か |
|---|---|---|
| `problem` | 課題駆動 | 現場の「困った」から始まる |
| `phenomenon` | 現象駆動 | 起きている現象の「なぜ」を問う |
| `method` | 手法駆動 | 使える手法が先にあり、使い道を探す |
| `data` | データ駆動 | 手元のデータで何が言えるかを問う |
| `improve` | 改良駆動 | 今ある手法をよくする |

### 2.2 何が起きたか

終わると、たくさんの行が出ます。次の 3 つが起きています。

1. フォルダの中に `.sai/` という隠しフォルダができ、論文の置き場（`.sai/paper/papr.db`）と研究方針の木が作られた。
2. エージェント（cc と pi）がこのプロジェクトで使う設定（`.mcp.json`・`.claude/`・`.pi/`）が置かれた。
3. プロジェクトが登録簿（`~/.sai-moon/registry.json`）に `sci-practice` という名前で載った。**これで Web の画面にこのプロジェクトが出ます。**

最後の方に `✅ 登録簿に登録しました: sci-practice` と出ていれば成功です。

> 隠しフォルダは Finder では見えません。見たいときは Finder で `⌘ + shift + .`（ピリオド）を押します。

### 2.3 画面で確かめる

ブラウザで **論文** タブを押します。上の方の 📁 の札が `sci-practice` になっていなければ、📁 を押して `sci-practice` を選んでください。

論文タブの中には、さらに次のタブがあります。

```
研究方針 / Dashboard / Discover / Library / Radio
```

**研究方針** を押すと、研究方針の木の画面になります（研究方針の木を使うプロジェクトでは、最初からこの画面が開きます）。

## 3. 研究方針の画面の見取り図

PC（横幅の広い画面）では次のように並びます。

```
┌───────────────────────────────────────────────────────────┐
│ 研究方針 | Dashboard | Discover | Library | Radio          │ ← 論文タブの中のタブ
├───────────────────────────────────────────────────────────┤
│ 種の文  ［？対象］の［？データの型］で［？小目的］を行う。…   │ ← A 種の文
│ 関門    （関門 1/7　出発点）                                │ ← B 関門
│ 負債    仕分けていない提案 0 | 読んだが反映していない論文 0 …│ ← C 負債
├───────────────────────────────────────────────────────────┤
│ [一覧][根の図][表]                                          │ ← D 表示の切り替え
│ ┌──────────────┐ ┌──────────────────────────────────────┐ │
│ │○ N1 背景      │ │ ○未決定 N12 小目的                   │ │
│ │  ○ N2 大目的  │ │ [決める][対象外][候補を足す]…        │ │ ← F 板
│ │  …           │ │ 次の一手 / 問い / 候補 / 知見 /       │ │
│ │○ N11 目的     │ │ 結び付き / 文献の流れ / 仕分け待ち / │ │
│ │  ○ N12 小目的 │ │ 行動の履歴 / 決定の記録               │ │
│ └──────────────┘ └──────────────────────────────────────┘ │
│   E 項目の一覧                                              │
└───────────────────────────────────────────────────────────┘
```

iPhone（横幅の狭い画面）では A〜E が縦に並び、一覧の項目を押すと F の板が下からせり上がる小窓で開きます。✕ で閉じます。

| 場所 | 何が出るか | いつ変わるか |
|---|---|---|
| A 種の文 | 研究を 1 文で言ったもの。決まっていない所は **［？項目名］**（橙色の点線）で出る | 項目を「決める」と、その値が入る |
| B 関門 | 今いる関門。押すと 7 つの関門の一覧（通った・まだ）と通る条件が出る | 条件の項目が決まると進む |
| C 負債 | 後回しの片付け物の数。0 のものは薄く出る。「仕分けていない提案」を押すと仕分けの画面へ | 提案が来る・論文を読むと増減する |
| D 切り替え | 一覧・根の図・表 | ― |
| E 一覧 | 項目と候補の並び。印（下の表）と「空欄の種類」の札が付く | 何かを変えるたび |
| F 板 | 選んだ項目の中身と操作のボタン | 何かを変えるたび |

### 項目と候補の印

| 印 | 意味 |
|---|---|
| ○ 未決定 | まだ決めていない項目 |
| ◐ 仮決定 | 仮に決めた項目 |
| ● 決定 | 決めた項目 |
| × 対象外 | 今回の研究では扱わない項目 |
| ◇ 候補 | 候補（まだ選ばれていない） |
| ◆ 選択 | 選ばれた候補 |
| ✕ 却下 | 外された候補 |
| ◌ 休眠 | 今は使わないが残しておく候補 |

### 空欄の種類（まだ決まっていない項目に付く橙色の札）

| 札 | 意味 |
|---|---|
| 未着手 | まだ何もしていない |
| 調査中 | 読む札やカードが動いている |
| 情報不足 | 知見や候補が足りない |
| 判断待ち | 材料はそろった。あなたが決める番 |
| 対立 | 支持と反証がぶつかっている |

決まった項目にも、灰色の札が付くことがあります。

| 札 | 意味 |
|---|---|
| 根拠不足 | 根拠の知見が無いまま決めた |
| 要再確認 | 上流の項目が後から変わったので、見直した方がよい |

### 板（F）のボタン

一覧で項目（例: **N12 小目的**）を押すと、右に板が出ます。住所（ブラウザの上の欄）は `…/#/papers/tree/N12` に変わります。

| ボタン | すること | この文書の章 |
|---|---|---|
| 決める | 候補を選んで項目を決める（理由は必須） | ⑧ |
| 再開 | 決めた項目を「未決定」に戻す | ⑨ |
| 対象外 | 今回は扱わない項目にする | ⑨ |
| 候補を足す | 候補を 1 つ足す（「選ぶ」「並べる」項目だけに出る） | ⑦ |
| 子の項目を足す | この項目の下に小さな項目を足す | ⑩ |
| 問いを足す | この項目について考えたい問いを足す | ⑩ |
| 知見を足す | 分かったことを出典付きで足す | ⑦ |
| 結ぶ | 論文・報告・ノート・検索セット・実行をこの項目に結び付ける | ⑤ |
| 文を直す | 項目の題と本文を書き直す | ⑩ |
| 線を引く | ほかの項目との関係（依存・由来・同型）の線を引く | ⑩ |

板の下の欄は次のとおりです。

| 欄 | 中身 |
|---|---|
| 項目ガイド | ▶ を押すと開く。この項目で何を考えるか・つまずきやすい所・「埋まった条件」 |
| 次の一手 | 今やるとよいこと。「カードを作る」でエージェントに頼める。「自分で行う」の札は自分でやること。一番下に「読む札を作る」 |
| 問い | 考える問い。「答える」「取り下げる」 |
| 候補 | 候補の表（状態・支持の数・反証の数・論文の数）と、選ぶ・却下・休眠・戻す のボタン |
| 知見 | この項目の知見と出典。「外す」 |
| 結び付き | 結んだ論文など。論文には「読み具合」「外す（墓標）」 |
| 文献の流れ | 検索 → 選別 → 読む → 反映 の数 |
| 仕分け待ち | この項目への提案のうち、まだ仕分けていないもの |
| 行動の履歴 | この項目に向けた読む札とカードの実行。「実行を開く」 |
| 決定の記録 | 決めた・戻した・却下した記録。消えずに残る |

> 画面の文字の横にある灰色の点線付きの言葉（「種の文」「関門」など）を押すと、その言葉の説明が出ます。

## 4. 論文を集める（Discover）

木に結ぶ論文を 1 本、Library に入れます。

1. **論文** タブ → **Discover** を押します。
2. 検索の欄に `seizure prediction EEG deep learning` と入れて **検索** を押します。
   - 「条件 ▸」を押すと、検索先（s2・pubmed・arxiv など）・年・件数を変えられます。
3. 結果の一覧から、読めそうな論文を 1 つ押します。
4. **⬇ ダウンロード** を押します。
   - 上の **進み具合** に「ダウンロード中 1 件」と出ます。1 分ほどかかります。
   - 誰でも読める（オープンアクセスの）論文だけが PDF まで入ります。
5. **Library** を押すと、入った論文が並んでいます。

**論文の番号の調べ方**: Library で論文を押すと、住所が `…/#/paper/sci-practice/1` のようになります。**最後の数字（この例では 1）がその論文の番号**です。以下では、この論文を「#1」と呼びます。

---

## 5. 論文を項目に結ぶ

論文を「小目的」の項目に結び付けます。

1. **研究方針** → 一覧で **N12 小目的** を押します（番号はプロジェクトによって少し違うことがあります。題が「小目的」の項目を探してください）。
2. 板の **結ぶ** を押します。右（iPhone では下）に小窓が出ます。
3. 次のように入れます。

| 欄 | 入れるもの |
|---|---|
| 相手 | **論文** を押す（ほかに 報告・ノート・検索セット・実行 がある） |
| 番号 | `1`（④で調べた番号） |
| 論文の役割 | **代表例**（ほかに 比較対象・課題の根拠・手法の供給元・データの出典・背景・反証。論文のときは必ず選ぶ） |
| 読み具合 | **未読** のまま |
| 理由 | 空でもよい（書くと記録に残る） |

4. **送る** を押します。

**画面のどこが変わるか**

- 下に「結び付けました」と出ます。
- 板の **結び付き** に `L1 論文 代表例 未読 <論文の題>` が出ます。
- 一覧の N12 の行に「論文 1」の札が付きます。

## 6. 読む札で論文を読み、知見を書く

「読む札」は、自分が論文を 1 本読むときの作業票です。読んで分かったことが、そのまま木の知見になります。

### 6.1 読む札を作る

1. N12 の板の **次の一手** の欄の一番下にある、青い **読む札を作る** を押します。
2. 小窓で次を選びます。

| 欄 | 中身 |
|---|---|
| 論文 | 結んである論文から選ぶ（#1） |
| 役割 | 代表例（結んだときの役割が入っている） |
| 深さ | 抄録（要旨だけ）・図（図と表まで）・精読（全部） |
| 目的 | 空なら「小目的のために #1 を読む」になる |

3. **作る** を押すと「run 1 の読む札を作りました」と出て、読む札の画面（住所 `#/papers/read/1`）に移ります。

> 結んでいる論文が 1 本も無いと、「先に論文を結び付けてください」と出ます。⑤に戻ってください。

### 6.2 読む札の画面

```
┌ この読む札 ─────────────────────────────┐
│ <論文の題>  2025  （まだ読んでいない）     │ ← 題を押すと論文が開く
│ N12 小目的 ・役割 代表例 ・深さ 精読       │
│ 小目的のために #1 を読む                  │
│ 研究方針へ戻る                            │
└─────────────────────────────────────────┘
[読み始める]
┌ 問いに答える ───────────────────────────┐
│ その研究が 1 回の研究で何を達成したかは？  │ ← 役割ごとの問い
│ 文 [                     ]               │
│ 場所 [ §3.2（空なら #1） ]                │
│ 向き [支持 ▼]    [知見を足す]              │
└─────────────────────────────────────────┘
┌ 入れた知見 ─┐   ┌ 終える ─┐
```

1. **読み始める** を押します。札が「読んでいる」に変わります。
2. 論文を読みます（題を押すと論文が開きます）。
3. 問いに答える形で、分かったことを書きます。
   - 文: `新生児の脳波から数分先の発作を予測することを到達点としている。`
   - 場所: `abstract`（空なら出典は `#1` だけになる）
   - 向き: 支持
4. **知見を足す** を押します。**入れた知見** に `F1 支持 …` が出ます。
5. **終える** を押します。
   - 知見が 1 つも無いまま終えようとすると、「反映しない理由」を聞かれます（1 語でも構いません）。
   - 終えると、研究方針の板に戻ります。

**画面のどこが変わるか**（N12 の板）

| 欄 | 変わり方 |
|---|---|
| 知見 | `F1 支持 … 出典: #1 abstract` が出る |
| 結び付き | L1 の読み具合が **反映済み** になり、`L2 実行 1` が増える |
| 文献の流れ | 選別 1・読む 1 になる |
| 行動の履歴 | `#1 sci-read review …`（「実行を開く」で実行の中身へ） |
| 一覧 | 読んでいる間、N12 の札が **調査中** になる |

> 「読んだが反映していない論文」（負債）は、知見を書かずに読み終えた論文の数です。

---

## 7. 候補と知見を足す

### 7.1 候補を足す

1. N12 の板で **候補を足す** を押します。
2. 題に `発作の予知` と入れて **送る** を押します（本文は無くてもよい）。
3. もう一度 **候補を足す** を押して、`発作部位の推定` を足します。

**画面のどこが変わるか**

   - 候補の板には「決める」「再開」「対象外」はありません。候補の状態は、親の項目（N12）の **候補** の表で変えます。
2. **知見を足す** を押して、次のように入れます。

| 欄 | 入れるもの |
|---|---|
| 文 | `数分先の発作予測で AUC 0.9 前後の報告がある。`（1〜3 文） |

**試してみよう（わざと失敗する）**: 文に数字（例 `0.85`）を書いて出典を空にすると、断られます。**数字を書くときは必ず出典が要る**決まりです。

## 9. 決めたことを戻す

決めたことは消えません。戻した記録も **決定の記録** に積み上がります。

### 9.1 選んだ候補を却下すると、項目は未決定に戻る

1. N12 の板の **候補** の表で、N25 の行の **却下** を押します。
2. 状態は「却下」のまま、理由に `練習のために一度外す` と書いて **送る**。

**画面のどこが変わるか**

- N12 が `○ 未決定` に戻り、種の文も `［？小目的］` に戻ります。
- 決定の記録に「候補を却下 対象: N25」と「再開」の 2 行が増えます。

元に戻すには、N25 の行の **戻す** を押し（理由を書いて送る）、もう一度 **決める** を行います。

| 候補の表のボタン | すること |
|---|---|
| 選ぶ | その候補を選んだ状態にする |
| 却下 | 外す（選ばれていたら、項目は未決定に戻る） |
| 休眠 | 今は使わないが残す |
| 戻す | ただの候補に戻す |

### 9.2 再開と対象外

- **再開**: 決めた項目を未決定に戻します。選ばれていた候補も候補に戻ります。
- **対象外**: 今回の研究で扱わない項目にします（`× 対象外`）。**再開** で戻せます。

## 10. 問い・子の項目・文・線

### 10.1 問い

項目には、最初から問いがいくつか付いています（例: N12 の `Q34 1 回の研究で何を達成するか`）。

- **答える**: 答えを書いて送ると、札が「答えた」になる。
- **取り下げる**: 要らない問いを下げる。札は「取り下げた」になる。
- **問いを足す**（板の上のボタン）: 自分で問いを足す。

### 10.2 子の項目を足す

**子の項目を足す** で、題（例 `確かめの範囲`）と型（選ぶ・並べる・書く・確かめる、複数可）を選んで送ると、その項目の下に新しい項目ができます。

### 10.3 文を直す

**文を直す** で、項目の題と本文を書き直せます。本文は種の文に入る値にもなります（「書く」項目のとき）。

### 10.4 線を引く

**線を引く** で、ほかの項目との関係を描きます。

| 線の種類 | 意味 |
|---|---|
| 依存 | この項目は、あの項目が決まらないと決められない |
| 由来 | この項目は、あの項目から出てきた |
| 同型 | 同じ形の問題 |

輪になる線（A が B に依存し、B が A に依存する）は断られます。引いた線は ⑭ の **根の図** で見えます。

## 11. エージェントに頼む（カード）

ここからは、エージェント（pi または cc）に木の仕事を頼みます。エージェントは木を**直接は書き換えません**。「提案」を出すだけです。

| 提案の種類 | 扱い |
|---|---|
| 知見・問い・結び付け・種 | **自動で木に入る**（あとで外せる） |
| 候補・項目の追加・決定・線・対象外 | **仕分け待ち**になり、あなたが採用すると入る |

### 11.1 カードを作る

1. 一覧で **N4 対象** を押します。
2. **次の一手** の「対象の候補を出す」の横の **カードを作る** を押します。
3. 小窓の欄は次のとおりです。

| 欄 | 中身 |
|---|---|
| ブロック | 頼む仕事の種類（16 本）。ここでは 💡 候補を増やす（`sci-ideate`）が入っている |
| 目的 | 必須。エージェントが何を達成するか |
| 期待する成果 | 任意 |
| 問い | 任意。この問いに答えてもらう |
| 実行するもの | pi か cc |
| 範囲 | エージェントに見せる木の範囲。空ならブロックの既定（節点・道・部分木・兄弟・全体の要約・目隠し） |
| 読み方 | 1 本を読むときだけ使う（目的先行・目的後付け） |
| 仮置き | `N12=発作部位` の形で、仮に決めたことにして考えてもらう（5 個まで） |

4. **作る** を押すと「run 2 のカードを作りました（sci-ideate）」と出ます。**run 2 を開く** を押すと、プロジェクトの画面（`#/project/sci-practice/list/2/task`）でそのカードが開きます。

主なブロック（全部で 16 本）:

| ブロック | すること |
|---|---|
| 🌱 研究の入口（sci-start） | 最初に木全体を埋め始める |
| 💡 候補を増やす（sci-ideate） | 候補を出す |
| ⚖ 比べる（sci-compare） | 候補を比べて推す |
| 🔍 確かめる（sci-probe） | 知見を確かめる |
| 🔎 外部を探す（sci-search） | 外の論文を探す |
| 📚 Library で答える（sci-lookup） | 手元の論文から答える |
| ✍ 文を書く（sci-draft） | 項目の文を書く |
| 🗣 議論（sci-debate） | 反対の立場から議論する |

### 11.2 実行する

1. **プロジェクト** タブ → `sci-practice` → **Dashboard** を見ます。常駐（デーモン）が止まっていたら **起動** を押します。
   - 常駐は、カードを実際に動かす裏方のプログラムです。プロジェクトごとに 1 つです。
2. **List** の `todo` の列にある `ID2/sci-ideate` を押し、**▶ 実行** を押します。
3. エージェントが動き始めます。カードは `todo` → `running` → `review` と列を移ります。
   - **cc を初めてこのフォルダで動かすとき**は、エージェントの窓に「このフォルダを信頼しますか」と出ます。「Yes, proceed」を選んで `return` を押してください。
   - エージェントが途中で確かめの質問をしてきたら、**ホーム** の質問の札か、エージェントの窓で答えます。
   - 様子は **会話** タブで見られます。止めたいときは **■ 終了** を押します。
4. 終わると、カードは `review`（確認待ち）に入ります。

**画面のどこが変わるか**

- 研究方針の N4 の板の **行動の履歴** に `#2 sci-ideate` が出ます。
- 自動で入る提案（問いなど）は、もう N4 の **問い** などに入っています。
- 仕分けの要る提案は、C 負債の **仕分けていない提案** の数と、N4 の板の **仕分け待ち** に出ます。一覧の N4 の行には「仕分け 2」の札が付きます。

> 常駐を起動せずに体験だけしたいときは、⑰の「エージェントの提案をまねる」の命令で、提案を手で出せます。

## 14. 根の図と表

研究方針の画面の D で切り替えます。

- **一覧**: ここまで使ってきた並び。
- **根の図**: 項目と候補を、左から右へ線でつないだ図です。青い線が親子、灰色の線がほかの関係です。上の **＋** **−** で拡大・縮小、**⤢** で全体を表示、**候補を隠す** で候補を消せます。図の箱を押すと、その項目の板が開きます。
- **表**: 選んだ項目の候補を、列（状態・支持・反証・論文・知見）で比べる表です。項目を選んでいないときは、下に出る一覧から項目を選びます。別の項目を見るときは **一覧** に戻って選び直します。

## 17. 同じことを命令（CLI）で行う

画面でできることは、すべて命令でもできます。エージェントもこの命令を使っています。
練習用のフォルダで行ってください。

```bash
cd ~/research/sci-practice
```

| したいこと | 命令 |
|---|---|
| 木の様子を見る | `sai-moon-paper sci status` |
| 項目の中身を見る | `sai-moon-paper sci node N12` |
| エージェントに見せる範囲を見る | `sai-moon-paper sci context --run 2`（⑪ のカードの番号） |
| 仕分け待ちの提案を見る | `sai-moon-paper sci proposals` |
| 墓標を見る | `sai-moon-paper sci tombstones` |
| 書き出しを作り直す | `sai-moon-paper sci export` |

木を変える命令は、1 行の JSON を `sai-moon-paper sci apply` に渡します。例として候補を 1 つ足します。

```bash
echo '{"op":"add_option","node":"N12","title":"発作の検出"}' | sai-moon-paper sci apply
```

`{"op":"add_option","result":"N29"}` のように出たら成功です。ブラウザの研究方針の画面で ↻ を押すと、N12 の下に候補が増えています。

### エージェントの提案をまねる

常駐を動かさずに仕分けを体験したいときは、次の命令でエージェントの提案をまねられます（`--run 2` は ⑪ で作ったカードの番号）。

```bash
echo '{"proposals":[{"op":"add_option","node":"N4","title":"新生児集中治療室の脳波","reason":"代表例の論文の対象"},{"op":"add_question","node":"N4","text":"新生児と成人で発作の見え方はどう違うか","reason":"対象を絞るため"}]}' \
  | sai-moon-paper sci propose --run 2 --block sci-ideate
```

- 問い（`add_question`）は `applied`（自動で入った）、候補（`add_option`）は `pending`（仕分け待ち）になります。
- ブロックが出せない提案（例: `sci-ideate` からの `decide`）は、「このブロックは decide を提案できません」と断られます。

### 書き出されるファイル

| ファイル | 中身 | 手で直すか |
|---|---|---|
| `.sai/paper/state.md` | 現況（Dashboard の「現況」） | 直さない（次の書き出しで上書きされる） |
| `.sai/paper/tree.md` | 木の全体を文章にしたもの（TUI の `o`） | 直さない |
| `.sai/paper/mind.md` | 土壌（Dashboard の「考え」） | **あなたが書く**。エージェントは書き換えない |

## 18. 片付け

rows = json.loads(p.read_text())
p.write_text(json.dumps([r for r in rows if r.get("name") != "sci-practice"], ensure_ascii=False, indent=2))

4. 練習用のフォルダを消します（ゴミ箱を通らずに消えます。名前を確かめてから打ってください）。

```bash
rm -rf ~/research/sci-practice
```
