# DATA_SIZE

データがいくつあるかを文で書き、足りるかを確かめる Q である。

数字だけを書いて終わりにしない。1 件がどれだけ重いかまで書くと、足りるかが判断できる。

件数が書けて、足りるかも判断できている。

## Q
データの量はどれだけか（件数・人数・期間）。

## Child Q
- データはいくつあるか
- クラスごとにいくつあるか
- その量で調べたいことを分けられるか

## Extract
- 件数・クラスごとの件数・1 件の記録時間
- 件数と結果の関係をどう書いているか

## Pitfall
- 総数だけ書いて、クラスごとの数を書かない
- 要素数が多い記録と少ない記録を足して、1 件と数える
- 学習と検証で分けられるかを確かめずに件数だけ書く
