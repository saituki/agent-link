# 新規性

自分の研究の新規性を、近い研究との差で示す項目である。近い研究 3 本を選んで並べ、その 3 本との差分表を書いて、自分の新規性がどこにあるかを 1 文で示す。

判定の決まりはこうである。近い研究 3 本との差分表で、核になる面（目的・仕組み・評価・対象・データ）の 1 つ以上が違う。または、組み合わせが唯一である。または、新しい領域への適用である（Scideator の定義にならう）。この 3 つのどれかで、新しさが言い切れるようにする。

差分表は次の形で書く。行は 5 つの面、列は自分の研究と近い研究 3 本である。

```markdown
| 面 | 自分の研究 | 近い研究 1（#番号） | 近い研究 2 | 近い研究 3 |
|---|---|---|---|---|
| 目的 | | | | |
| 仕組み | | | | |
| 評価 | | | | |
| 対象 | | | | |
| データ | | | | |
```

## 問い
- 自分の研究と、近い研究 3 本のどれが、どれだけ違うか。
- その差は、内容そのものの差か、それとも組み合わせの唯一性か。
- その差は、1 つの研究で答えられる形になっているか。

## 埋まった条件
- count(novelty.closest, 3) かつ decided(novelty.diff)

近い研究 3 本との差分表で、核になる面（目的・仕組み・評価・対象・データ）の 1 つ以上が違うと確認できていて、かつその違いを自分の言葉で書けているときに埋まる。

## 抜き出す項目
- compare: 近い研究それぞれの目的・仕組み・評価・対象・データ
- exemplar: 自分の研究と比較する代表論文の要約

## 落とし穴
- 近い研究を 3 本並べただけで、差分表を書かない。
- 3 本が同系統で、他の分野に隣接した研究が入っていない。
- 差が一面的で、「前に似た研究が無い」ではなく「前に似た研究が要る場面」だと示している。
