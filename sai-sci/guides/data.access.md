# DATA_ACCESS

そのデータを手にできるかを確かめる Q である。

「公開されている」と「使える」は違う。条件と手続きを確認して初めて使えるものになる。

入手の行き先が決まって、条件と手続きが分かっている。

## Q
そのデータを実際に手にできるのか。

## Child Q
- 公開されているデータはあるか
- 使うときの条件（申請・ライセンス・倫理審査）は何か
- 入手までどれくらい時間がかかるか

## Extract
- 入手先・申請先・ライセンス・利用の制限
- そのデータを実際にどう手に入れたか

## Pitfall
- 論文にデータ名があっても、今も入手できるとは限らない（リンク切れ・申請制）
- ライセンスの条件を見ずに使い始める
- 倫理審査に時間がかかることを考えず、計画に組み込む
