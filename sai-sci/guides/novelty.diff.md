# NOVELTY_DIFF

近い研究 3 本と自分の研究の新規性を、5 つの面（目的・仕組み・評価・対象・データ）を並べた差分表で示すITEM である。

判定の決まりはこうである。近い研究 3 本との差分表で、核になる面（目的・仕組み・評価・対象・データ）の 1 つ以上が違う。または、組み合わせが唯一である。または、新しい領域への適用である（Scideator の定義にならう）。

差分表は次の形で書く。行は 5 つの面、列は自分の研究と近い研究 3 本である。

```markdown
| 面 | 自分の研究 | 近い研究 1（#番号） | 近い研究 2 | 近い研究 3 |
|---|---|---|---|---|
| 目的 | | | | |
| 仕組み | | | | |
| 評価 | | | | |
| 対象 | | | | |
| データ | | | | |
```

## QUESTION
- 自分の研究は、近い研究 3 本と、どの面で違うか。
- その違いは、1 面だけで十分か。複数の面にまたがるか。
- 他の研究にもその差はあるのか。本当にあたらしい差はどれか。

## CONDITION
- decided(novelty.diff)

差分表に、5 つの面のどれかが埋まり、近い研究 3 本のどれとどの面が違うかが示せていれば埋まる。3 本とも同じ面が空欄だと、比較していないので埋まらない。

## EXTRACT_FIELDS
- compare: 目的・仕組み・評価・対象・データ の 5 つの面それぞれの記述
- exemplar: 近い研究 3 本で、核になる面の記載箇所

## PITFALL
- 差分を「精度が高い」だけにする（面の違いになっていない）。
- 自分の研究だけを詳しく書いて、近い研究の面を空欄にする。
- 差分表にない面だけを、文章で足している。
