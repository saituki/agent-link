# DATA_TYPE

データの型に ★ を付けて答える Q である。波形か、数値か、画像か、文章か。扱いがすべて変わるので、最初に決める。

型が決まると、量とラベルの付け方も決まる。

型が 1 つに決まっている。

## Q
データの型は何か（波形・数値・画像・文章など）。

## Child Q
- どんな型のデータか
- その型で何が測れるか
- ほかの型と混ぜなくてよいか

## Extract
- データの型・測定機器・サンプリング・単位
- その型を前提とした前処理・予測の設定

## Pitfall
- 型を「データ」など抽象的に書いて、決める意味を失う
- 処理しやすさを基準に選んで、測っている対象を無視する
